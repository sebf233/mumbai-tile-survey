# Mumbai tile survey: slum-mask review

Static copy of the Mumbai tile survey page (Esri Wayback zoom-18 imagery, Jan 2016 vs Dec 2016) with the
slum-mask review. Open the Pages site, step through the tiles, approve or edit each mask, then use
"Download approved masks" to send the JSON on. Approvals are kept in your browser only.

Built by `esri_wayback/build_mumbai_site.py --masks` in https://github.com/mksifakis/slumworldML.
Imagery: Esri World Imagery Wayback releases 29387 and 25521.
